# WrapPin 1.0.26（Build 94）— SideStore + Shadowrocket

## 下載及安裝

**[下載 Standard／SideStore 安裝包 ZIP](https://github.com/kkycble/WrapPin/actions/runs/44565587160/artifacts/14550359597)**

如有提示，請登入 GitHub。此 Actions 成品保留至 **2026-12-19**，不是上游的正式發佈。

1. 解壓縮 ZIP，取得 **`WrapPin-Standard-1.0.26-build94-unsigned.ipa`**、`SHA256SUMS.txt` 及 `receipt.json`。
2. 將 IPA 儲存至 iPhone 的「檔案」App。
3. 在已完成設定的 SideStore，開啟 **My Apps → +**，選取這個本機 IPA，由 SideStore 簽署及安裝。不要安裝 Tunnel 版。
4. 保持開發者模式開啟。覆蓋更新時盡量沿用原有簽署身分，以保留本機設定及配對資料。

**IPA：**7,162,726 bytes；iOS／iPadOS 18.0+；arm64 真機；支援 iPhone／iPad。

**SHA-256（IPA，不是外層 ZIP）：**

```text
0bb1db7b70c6c57a640d347fcc9bfa86e8eea96bf591f270c46337a6f3900b6f
```

可在電腦解壓縮後核對：

```sh
shasum -a 256 WrapPin-Standard-1.0.26-build94-unsigned.ipa
# 或在本目錄有 IPA 與 SHA256SUMS.txt 時：
shasum -a 256 -c SHA256SUMS.txt
```

## 繁體中文與 Shadowrocket

- App 跟隨系統語言。也可在 iOS **設定 → App → WrapPin → 語言** 選擇繁體中文；香港與台灣的繁體偏好均適用。
- 在 WrapPin 首次設定或 **設定 → 隧道跳轉應用** 選擇 **Shadowrocket**。
- 在 Shadowrocket 開啟 **Include Route 10.7.0.1/32／包含路由 10.7.0.1/32**，連接 VPN，然後返回 WrapPin。普通代理連線不足以提供本機裝置通道。
- 有可用的 Shadowrocket 裝置通道時，**WrapPin 毋須 LocalDevVPN**；SideStore 自身仍須符合其安裝及續期要求。先用 Wi-Fi 測試，這次改動沒有修復 Shadowrocket 原有的流動網絡限制。
- iOS 18–26 需匯入電腦產生的 **RPPairing**，iOS 27 可使用本機配對。SideStore 的 `.mobiledevicepairing` 不能代替 WrapPin 的配對檔案。

## 單車模擬

選擇目的地 → **預覽單車** → 調整速度 → **開始單車模擬**。

預設 **18 公里／小時**，範圍 **1–60 公里／小時**，支援暫停／繼續、地圖跟隨、中斷後手動復原。到達後保持終點，結束時用 **停止模擬並恢復**，再於 Apple 地圖確認真實位置。

若當地 Apple 地圖不提供單車路線，會提示改用自訂路線或 GPX，不會靜默替換成步行／駕駛。Apple 單車路線不直接倒轉；返程請重新規劃。
